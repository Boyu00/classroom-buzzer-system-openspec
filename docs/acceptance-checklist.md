# 人工驗收清單（tasks 9.2／#21）

目的：以**真實線上 Google Sheets** 加老師與至少兩組學生，走完 spec.md 第 8 節 AC-01～AC-24，兩種模式都要驗。自動測試與假替身**不能代替**這份清單；每項只有在這裡填了日期、環境與證據才算通過，沒做就維持「未測」。

狀態圖例：✅ 已有真實證據　🟡 有自動測試，真實／人工尚未做　⬜ 尚未做

## 一、準備（做一次）

| 項目 | 做法 |
| --- | --- |
| Node 版本 | PowerShell 執行 `node -v`，必須是 v24.22.x（預設已設定；若不是，先 `conda activate node24`） |
| 啟動 | 在專案資料夾 `npm start`，開 http://127.0.0.1:3000 |
| 瀏覽器（**每個角色必須是獨立的工作階段**） | 建議配置：**老師 Chrome 一般視窗**（`/teacher.html`）、**學生甲 Chrome 無痕視窗**、**學生乙 Edge InPrivate**（`/student.html`）；需要第三組（AC-04）時，用第三個獨立的瀏覽器設定檔，或另一台裝置的瀏覽器。也可以全部改用三個各自獨立的瀏覽器設定檔。**注意：同一個 Chrome 設定檔開兩個無痕視窗仍共用同一個工作階段（Cookie），不能當作兩組學生**——後開的視窗可能直接恢復第一組，導致雙組受理、隱私、公平模式都無法正確驗證。老師與學生也不能共用同一個瀏覽器工作階段。 |
| 服務帳戶 | 試算表要分享給 `classroom-buzzer@majestic-lodge-515506-h6.iam.gserviceaccount.com`，寫回需**編輯者** |
| 乾淨資料庫（可選） | 停止伺服器後刪除 `data/classroom.sqlite3`（本機資料，刪前確認） |

**開始前的自我檢查**：讓甲、乙分別加入後，老師頁應同時看到「甲組、乙組」兩組；若只看到一組，代表兩個視窗共用了工作階段，請改用上面的配置。
