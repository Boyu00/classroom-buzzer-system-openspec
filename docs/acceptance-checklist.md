# 人工驗收清單（tasks 9.2／#21）

目的：以**真實線上 Google Sheets** 加老師與至少兩組學生驗收 spec.md 第 8 節，包含兩模式的 AC-01～AC-24 及 v1.3 新增 AC-25／26。每項依實際人工、Console／API 或已明確約定的自動證據判定，不將假替身結果冒充人工操作；未執行者不標通過。AC-06／10 已由兩人確認採自動測試，其餘層級及限制逐項留證。

狀態圖例：✅ 人工在真實環境驗證過　🤖 **自動化的真實 Sheets 驗證已通過（腳本驅動真實 Chrome 與真實試算表），尚未人工驗收**　🟡 有自動測試，真實驗證只做了一部分　⬜ 尚未做

自動化的真實驗證證據在 `docs/writeback.md`（2026-11-22、2026-11-25）。它能證明系統在真實 Sheets 上的行為，但**不能取代**這份清單要求的人工操作（真實瀏覽器雙視窗、Excel 開檔、重啟伺服器等）；人工驗完才在紀錄表標通過。
