# 學生操作頁（member A #12）

入口：`/student.html`，首頁也提供「前往學生搶答頁」。先依 README 啟動服務；教師與 Sheets 整合另由 member B #13～#16 提供。本頁沒有測試題目或假匯入端點；教師尚未匯入與開啟活動時，不能用本頁假裝完成搶答。

## 學生操作

1. 老師與每個學生組使用獨立瀏覽器工作階段，例如一般 Chrome 與一個無痕視窗。多個一般分頁共用 Cookie；多個無痕視窗也通常共用同一個無痕工作階段，不能當成多組。
2. 輸入六碼加入碼及組名。加入碼不分英文字母大小寫，組名去除前後空白後 1～30 個 Unicode 字元。活動必須準備中，組名不可重複；教師身分無法直接用同一工作階段當學生。
3. 加入後顯示自己的組別、階段、模式與規則。準備中可以看題號，請等待老師開啟；收到授權同步快照後才開放送出。
   若組名打錯，準備中可按「退出組別並重新加入」；伺服器確認後移除本人組別、撤銷舊學生身分並回到加入頁，可重填加入碼與更正組名。按鈕在離線或處理中停用，OPEN／CLOSED 不提供退出；後端仍獨立驗證階段，不能藉退出刪除已受理答案。回覆不確定時先重新取得 session，不直接宣稱成功。
4. 單題填寫答案後按「送出答案」；題組須全部填妥後按「整組一起送出」。每題不可全空白，最多 1,000 個 Unicode 字元；emoji 算一字，保留前後空白及換行。可用 Tab 移動、Enter 啟動按鈕，textarea 的 Enter 則換行。
5. 送出中顯示「尚在確認受理」。收到 HTTP 受理回覆或授權快照中的受理紀錄後，顯示伺服器保存的原文與 UTC 受理時間，隱藏編輯表單；每組每單位只接受第一筆有效答案。搶答中不顯示他組資料、數量、順位或全場序號。
6. 若未收到回覆，不會直接宣稱成功。保留本頁原稿，使用「確認最新活動與受理紀錄」查詢；恢復連線後亦可重試同單位，後端會去重並回傳第一次受理。沒有被受理的送出，若活動已結束則不能補交。
7. 結束後停止新增作答，保留自己的受理。共用結果頁由 B #16 整合，未存在時明示「共用結果頁待整合」，不導向不存在的頁面。

## 恢復與錯誤

刷新、SSE 重連及服務重啟使用原 Cookie 恢復原組別與伺服器紀錄；未送出草稿只留在目前頁面，不承諾刷新後保存。「重新確認身分與活動」會清除目前表單，重新以 Cookie 讀取；適用身分失效、加入結果不確定或 CSRF 改變時。

2026-11-22 使用者確認沿用既有規則：Cookie 遺失、到期或登出後，不能只靠組名接管原組；顯示說明並請洽老師。本頁不另加跨裝置接管或延長工作階段，也不自動登出。2026-11-27 跨組對齊增加準備中本人主動退出，明示原身分失效；不等於提供無 Cookie 的接管。教師建立下一個活動時，若原學生已在 CLOSED 舊組，仍需用新的獨立工作階段加入。

斷線會顯示文字提示並暫停送出。HTTP／SSE 的競態保留最新階段與已確認受理；在途 HTTP 快照不覆蓋較新的 SSE，工作階段失效後也不能用舊回覆恢復作答。常見加入、內容及 CSRF 錯誤使用本地提示，不反射未知後端細節。

所有組名、題號與答案都以文字 DOM 呈現，腳本與公式不執行；CSP 保留禁止內嵌腳本／樣式。每個欄位有 label、題號、字數提示與錯誤；狀態有文字及 aria-live，不只靠顏色。快照不重建既有表單，避免清除草稿或打斷鍵盤焦點。

## B 的結果頁接點

約定 `/results.html?activityId=<活動 ID>`，由同源 Cookie 驗證；不可把 session／CSRF 放進 URL。學生頁僅於 CLOSED 探測 `/results.html` 的 HEAD；存在且為 HTML 才顯示連結，否則保留待整合提示。B 完成 #16 後請一起驗證結果 API 授權、各組固定順位、無人作答與模式。若採用其他路徑，請一併更新 student-page.js、對應測試與本文件；不要以 API JSON 當成已完成共用結果頁。

## 驗證範圍

`tests/student-page.test.js` 使用固定版本 linkedom（僅 devDependency）驅動實際 HTML／表單，涵蓋加入、CSRF 旋轉、Unicode 邊界、原文、雙擊、未確認回覆、斷線、同名組拒絕、失效及舊快照競態、結果入口。另以兩個獨立 Cookie jar 驅動真實 HTTP API，驗證單題／題組、隱私、刷新與 FAIR 結果；既有 submissions/events 測試涵蓋重啟與 SSE。

2026-11-22 另用一般 Chrome 及無痕工作階段操作獨立記憶體 fixture：兩組加入與等待、SSE 開啟、鍵盤填答、A 單題／題組與腳本字串、B 獨立送出、互不顯示他組答案、刷新恢復、CLOSED 鎖定及結果頁待整合皆已觀察。本機 fixture 控制程式只放忽略的 tmp，驗證後停止；這不是產品匯入功能，也不代表真實 Sheets 或全項人工 AC 驗收。
