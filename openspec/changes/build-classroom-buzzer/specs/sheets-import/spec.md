# Spec Delta

## Purpose

讓老師從自己的雲端 Google Sheets 匯入 Guided Notes，透過明確標記識別單題與題組，預覽後保存原格對應與穩定順序。不同版面與不連續題號仍須正確處理，並為結束後安全寫回提供依據。

## ADDED Requirements

### Requirement: 直接讀取雲端題目
系統 SHALL 讓教師提供 Sheets 網址或 ID、依序選擇工作表，由後端以服務帳戶讀取雲端原表；教師將副本分享編輯權限給服務帳戶。不得以本機上傳、離線樣本或下載檔案替代線上匯入。對應 FR-02、第 7 節、AC-01、AC-03。

#### Scenario: 真實 Sheets 匯入
- **WHEN** 教師對已授權試算表選擇工作表並要求讀取
- **THEN** 系統直接讀取線上值與結構，顯示實際解析結果

#### Scenario: API 或授權失敗
- **WHEN** 來源無權限、斷網或 API 失敗
- **THEN** 系統明示失敗，保留上次完整匯入，不使用樣本假裝成功

### Requirement: 標記與動態原格映射
系統 SHALL 解析完整格值的 `{{Q:題號}}` 或 `{{Q:題號|G:題組代號}}`，解析前可去除前後空白；識別字限非空英數字、點、底線、連字號。題號在匯入範圍唯一，可不連續，逐題保存試算表、工作表、原格位置與原標記，禁止寫死座標。對應 FR-02、AC-01、AC-02。

#### Scenario: 換版面與非連續題號
- **WHEN** 教師匯入另一份格位不同且題號為 1、4、9 的表
- **THEN** 系統產生三題，保留原題號，原格映射與新來源一致

### Requirement: 題組與固定掃描順序
系統 SHALL 按選定工作表順序及列、欄順序掃描；相同題組代號的至少兩題合為一個單位，可跨工作表，單題各自成單位。單位排序取首成員位置，組內依掃描順序，題數按答案格計。對應 FR-08、AC-17。

#### Scenario: 混合題組
- **WHEN** 表內有兩個單題與分散在所選工作表的三題同組題目
- **THEN** 預覽顯示五題、三個單位，組內及單位順序固定且各題映射正確

### Requirement: 預覽確認與完整替換
系統 SHALL 在 PREPARING 顯示題號、題數、單位數、題組成員與原格位置，教師確認後才整批取代舊匯入。零題、非法或重複標記、單一成員題組、合併答案格均拒絕，失敗不保留部分新資料。對應 FR-02、AC-03、AC-17。

#### Scenario: 無效來源
- **WHEN** 解析遇到任一不合法條件或教師未確認預覽
- **THEN** 舊題目與映射保持完整，不以不完整新資料取代

#### Scenario: 開啟後使用舊預覽
- **WHEN** 教師在活動開啟後要求確認匯入
- **THEN** 系統拒絕修改，保持原固定單位順序與映射
